# Sunday service checklist

A simple run-through for using Kyro on a service day. Print it, or keep it open on a phone.

## The week before

- [ ] **Rota:** upload this Sunday's rota so Kyro knows who's on stage and when. → [Rota](/pages/rota)
- [ ] **Phones:** every leader who wants alerts has [turned on notifications](/guides/phone-alerts) and tested with **Send in 20s**.
- [ ] **Accounts:** new ushers have an account with **Manual Count** access. → [Users](/pages/users)

## Before doors open

- [ ] **Start the cameras.** On the camera computer, open [Camera Mode](/pages/camera-mode) and press **Start counting** (or it starts by itself if you ticked that box). Using the installed version? It's already running.
- [ ] Open [Live Cameras](/pages/live-cameras). Every camera shows **Live**.
- [ ] Admins: check **System Status** on [AI Count](/pages/ai-count). All three rows are green.
- [ ] Start a **session** for each room, named for the service, for example *Sunday Morning Service*. → [Sessions](/pages/sessions)
- [ ] Reserve seats for guests on the [Seat Map](/pages/seat-map) (**Reserve Unit**).

## During the service

- [ ] Watch for **Rooms filling up** on [Live Cameras](/pages/live-cameras). Send ushers to the overflow room before a room is full.
- [ ] Check **OUTSIDE QUEUE** to see whether the people waiting will fit.
- [ ] Answer **AI questions** when they pop up. → [AI questions](/guides/ai-questions)
- [ ] Ushers count rooms without cameras on [Manual Count](/pages/manual-count): **Review & submit** → **Confirm & save**.

## After the service

- [ ] Camera Mode: press **Stop** once everyone has left (or just close the page).
- [ ] **End every session.** The green dot next to **Sessions** should stop.
- [ ] **Approve the final count** on [Manual Count](/pages/manual-count).
- [ ] **Send the total**: it goes automatically if you've set a schedule on [Integrations](/pages/integrations); otherwise tap **Send today's total now**.
- [ ] Look at **Arrival & exit times** on [AI Count](/pages/ai-count). When did most people arrive? Plan next week's door team around it.

::: tip Practise in Demo mode
Run through this checklist in **Demo mode** with a new team member. Everything works the same way, and nothing affects real data.
:::
