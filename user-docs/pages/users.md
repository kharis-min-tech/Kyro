# Users

The Users page is where administrators create accounts for the team and choose which pages each person can use.

<Shot name="users" alt="Users page with the Add a new user form and page access chips, and the list of users with their roles and pages" />

## Add a user

1. Fill in **Username** (for example *john.doe*), **Display name** and **Password** (at least 8 characters).
2. Under **Page access**, tap the pages they should see. A ✓ shows a page is on.
3. Check the role badge, for example **→ operator**. It updates as you tick pages. See [Roles & access](/getting-started/roles).
4. Tap **Create user**.

::: tip Keep it simple for each person
An usher who only counts rooms needs **Manual Count** and maybe **Seat Map**. Fewer pages means less to learn.
:::

## Change what someone can see

1. Tap **Edit access** on their row.
2. Tap pages on or off. The **Role** badge updates.
3. Tap **Save access**.

::: warning Some pages make someone an admin
Ticking **Seat Editor**, **Integrations** or **Users** makes that person an administrator.
:::

## Passwords

Tap **Password** on a user's row, then **Change password**. Enter the new password twice (at least 8 characters) and tap **Save password**.

## Remove a user

Tap **Remove** and confirm. In Live mode the account is deactivated, so the person can no longer sign in.

The built-in **admin** account always has full access.
